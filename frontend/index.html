import requests resp = requests.post( "https://voice.axiogen.in/v1/audio/speech", headers={"Authorization": "Bearer YOUR_API_KEY"}, json={ "model": "axiogen-v2", "input": "Hello from Axiogen!", "voice": "af_bella", "speed": 1.0 } ) with open("speech.wav", "wb") as f: f.write(resp.content)

📚 API Reference

Base URL

https://voice.axiogen.in

Authentication

Include your API key as a Bearer token: Authorization: Bearer YOUR_API_KEY

Endpoints

POST /v1/audio/speech

Generate speech from text. OpenAI SDK compatible.

{ "model": "axiogen-v2", "input": "Text to convert to speech", "voice": "af_bella", "speed": 1.0 } // Returns: audio/wav binary
GET /v1/voices

List all available voices with metadata.

GET /v1/models

List available models.

GET /health

Health check — returns engine status.

OpenAI SDK Compatible

from openai import OpenAI client = OpenAI( base_url="https://voice.axiogen.in/v1", api_key="YOUR_API_KEY" ) response = client.audio.speech.create( model="axiogen-v2", voice="af_bella", input="Hello from the OpenAI SDK!" ) response.stream_to_file("output.wav")
